# Controles

## Desktop (teclado e mouse)

| Entrada | Ação |
|---|---|
| `W A S D` ou setas | Flutuar pela arena (8 direções) |
| Mouse | Mirar |
| Não segurar nada | Rajadas de energia automáticas na direção da mira |
| Segurar clique esquerdo (ou `J`) | Raio Cósmico |
| `Espaço` (ou `E`) | Apagar da existência |
| `Shift`, botão direito (ou `L`) | Teleporte até a mira |
| `Q` | Parar o Tempo (depois de desbloqueado) |
| `1` `2` `3` | Escolher carta na tela de evolução |
| `P` ou `Esc` | Pausar / continuar |
| `M` | Ligar / desligar som |

Observações:
- As rajadas são automáticas e infinitas. Segurar o clique troca as rajadas pelo raio.
- O menu do botão direito do navegador fica desativado sobre a arena.
- Ao trocar de aba ou janela, o jogo pausa sozinho.
- A mira é um retículo de pixels desenhado no canvas.

## Celular (toque)

O modo toque liga automaticamente em telas sem ponteiro fino, ou no primeiro toque na arena.

| Entrada | Ação |
|---|---|
| Arrastar nos 60% esquerdos da tela | Joystick virtual (aparece onde o dedo tocou) |
| Mira | Automática no inimigo mais próximo |
| Botão **RAIO** (segurar) | Raio Cósmico |
| Botão **APAGAR** | Apagar da existência |
| Botão **TELEPORTE** | Salta 110 px na direção do movimento |
| Botão **PARAR TEMPO** | Aparece depois de desbloquear o poder |
| Tocar numa carta | Escolher evolução |

No celular, os indicadores de poder do HUD são trocados pelos botões. Um botão fica translúcido enquanto o poder recarrega.

## Som

O áudio só começa depois da primeira interação (clicar em **DESPERTAR**), por regra dos navegadores. A tecla `M` funciona a qualquer momento.
